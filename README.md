# First mini GAME - SIMON SAYS
A simple and interactive Simon Says memory game built using HTML, CSS and javascript.

# How to play
1. Press any key to start the game.
2. Watch the color sequence carefully.
3. Click the button in the same order as the sequence.
4. If your sequence i scorrect, the game moves to the next level.
5. If you click the wrong button, the game ends.
